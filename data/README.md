# Data availability

No original geodatabases, satellite imagery, private datasets, feature-class exports, model weights, or project workspaces are published here.

The original workflow requires prepared OSM-derived roads, damage road sections, emergency service locations and target points. The script inputs and outputs should be inspected in the original ArcPy code once publication is authorized.

Do not assume public OSM access automatically authorizes redistribution of all derived or combined project datasets.
