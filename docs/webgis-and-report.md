# WebGIS and report

The original project report is a 42-page document titled *Geospatial Data Processing to Support Seismic Emergency Management: WebGIS services to support the roads management in the post-event emergency and early recovery phases*.

It covers:
- **Part I:** Seismic vulnerability and damage scenarios for Norcia and 25 Central Italian municipalities.
- **Part II:** Road-network preparation, confirmed and uncertain road damage, emergency access analysis, custom Dijkstra routing, response corridors and reopening priorities.

The curated GitHub repository will emphasize the strong Part II code and engineering decisions. The exploratory ML screening code is not part of the public code showcase.
