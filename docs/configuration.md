# Configuration of the published ArcPy scripts

These are **publication-safe adaptations** of the five selected original GPEM scripts. The analytical algorithms were not rewritten: modifications are limited to machine-specific file paths, a configurable optional hosted road layer, and the default output-deletion setting.

## Required environment

- ArcGIS Pro installed on Windows, with its compatible ArcPy Python environment.
- A working ArcGIS Pro project (`.aprx`) containing the original relevant OSM import layer where needed.
- The original geodatabase feature classes and field schemas. See [Architecture](architecture.md). **Project datasets are not included.**
- For the routing and priority scripts, source geometries must have a valid spatial reference; working routing coordinates use EPSG:3065.

## Configuration variables

| Variable | Purpose | Default |
| --- | --- | --- |
| `GPEM_APRX_PATH` | ArcGIS Pro `.aprx` project | `CURRENT` (requires ArcGIS Pro Python window/session) |
| `GPEM_MAIN_GDB` | Existing geodatabase with the required layers | Placeholder `C:\path\to\your_project.gdb` (must replace) |
| `GPEM_QA_DIR` | Folder where QA CSV outputs are created | `qa` |
| `GPEM_CLEAR_OUTPUT` | Permit deletion/replacement of existing final output feature classes | `false` |
| `GPEM_ROADS_SERVICE_URL` | Optional hosted FeatureServer fallback for Script 27 | Empty; use a named raw roads layer in the map |

Example in PowerShell (substitute your own valid paths):

```powershell
$env:GPEM_APRX_PATH = "C:\GIS\study.aprx"
$env:GPEM_MAIN_GDB = "C:\GIS\study.gdb"
$env:GPEM_QA_DIR = "C:\GIS\qa"
$env:GPEM_CLEAR_OUTPUT = "false"
# Optional if the raw road layer is not present in your map:
# $env:GPEM_ROADS_SERVICE_URL = "https://your-authorized-host/FeatureServer/0"
```

## Safe execution notes

- `GPEM_CLEAR_OUTPUT=false` makes existing *final output feature classes* trigger an error instead of being deleted. It is **not** a dry-run: ArcPy still creates and edits layers, and Script 27 can replace its fixed-name temporary import layer.
- The original `arcpy.env.overwriteOutput = True` setting remains in the scripts; review paths and work from a disposable geodatabase copy.
- `GPEM_CLEAR_OUTPUT=true` intentionally re-enables the original final-output recreation behavior.
- The scripts do not provide a complete installer or universal data schema. In particular, Scripts 29 and 31 depend on previously prepared damage-section layers not generated by the published five-file selection.
- If Script 27 cannot find the raw OSM layer in the map and `GPEM_ROADS_SERVICE_URL` is blank, it now fails with a configuration error rather than trying the private project-specific hosted URL.
- Code can be syntax-checked with standard Python, but importing/running these scripts requires ArcPy.

**Do not treat the computed routes as live dispatch directions or confirmed passability.**
